# XYDSignTool

XYDSignTool 是一套面向 AutoCAD 2018-2026 的效率插件，主要用于标识系统算量、图纸目录管理、批量出图、图框识别、统计测量和批量嵌图等制图流程。

当前版本：**V1.3 / 1.3.0.0**。[V1.3 使用教程](Docs/V1.3使用教程.md) 包含映射模板、跨文件回写、电子签首次配置和线段容差操作。

[下载 V1.3 安装包](https://github.com/XYD-Studio/XYDSignTool/releases/download/V1.3/XYD_Toolkit_V1.3_AutoCAD2018-2026_Setup.exe) · [发布说明](Docs/V1.3发布说明.md)。安装或覆盖更新前请关闭所有 AutoCAD 窗口。

本项目由 **玄宇绘世设计工作室** 免费开源发布。

GitHub 仓库地址：<https://github.com/XYD-Studio/XYDSignTool>

## 功能概览

- 图库中心：插入标识块、标准图框和自定义 DWG 图库中的命名图块，可按图库设置需要显示的图块。
- 自定义图框识别：适配用户公司已有属性块图框，可配置块名前缀和图名、图号、比例、图幅字段映射。
- 标识系统算量：识别图库中心标识图块，生成数量表、Excel、JSON 和概算清单，并可双向编辑标识的用电量、备注等全部业务属性。
- 出图与目录：识别模型空间和布局空间图框，批量导出 PDF，管理并双向回写图框目录属性。
- 统计与测量：图块计数、动态块长度统计、规格统计、线段总长、批量查字段、批量文本替换、查找相同、自动排号、批量旋转和批量缩放。
- 图片工具：批量嵌入图片到 CAD 图纸中。
- 帮助页面：内置插件说明、使用教程、定制开发联系方式和版权声明。

## 基本使用

1. 在 AutoCAD 中加载 `XYDSignTool.dll`。
2. 切换到 `XYD 工具集` Ribbon 选项卡。
3. 按需求使用图库中心、标识系统算量、出图与目录、统计与测量、图片工具等功能。
4. 如使用公司自有图框，先通过 `图框识别` 配置识别规则。
5. 批量出图前，建议先检查图框中的图名、图号、比例、图幅属性是否完整。

Ribbon 使用小图标配短文字、每列最多三行的紧凑布局，减少面板折叠。鼠标停留在按钮上可查看完整功能名和命令；图库下拉列表也使用小图标。文字和图标按 AutoCAD 的显示缩放设置显示，窗口较窄时采用 CAD 的自适应布局。

小按钮与菜单的矢量图标使用完整的 16×16 逻辑尺寸，大图使用 32×32，避免裁切并适应 DPI。`XYD_MSCALE` 批量缩放以各对象自身 WCS 包围盒中心（含真实 Z）为基点，输入 2 放大两倍、0.5 缩小一半，默认 1 不改动；支持预选、图块属性联动、逐对象回滚和整次撤销。

批量出图只提供有效 CTB。对 STB 图纸自动在完整临时副本中转换后打印，使用预检中选定的 CTB；已打开图纸的未保存内容也参与打印，源 DWG 保持不变。支持 `XYD_BATCHPRINT_CANCEL` 取消队列，转换或样式验证失败时报告原因并跳过输出。

如果 CAD、天正和 XYD 的工具栏同时消失，先依次执行 `CLEANSCREENOFF`、`RIBBON` 恢复显示，再执行 `XYD_UI` 刷新 XYD。自动加载保留当前选项卡；只有手动执行 `XYD_UI` 才切换到 XYD。加载异常保存在 `%APPDATA%\XYDSignTool\Ribbon.log`，连续失败会停止自动重试，避免影响 CAD 界面。

## 标识算量说明

标识系统算量通过识别图库中心插入的标识图块进行统计。插入标识图块后，可以修改属性，系统会自动识别。

属性块中如果没有数量属性，则默认数量为 `1`。

如果需要用一个编号表达多个连续标识，请使用英文波浪线 `~` 连接，例如：

```text
ZF-XQ-01~03
```

该编号会被识别为 3 个标识。请注意，其他连接符号无效。

系统中的单价仅供参考，不作为结算、审计或其他正式依据。

## 图框与目录说明

插件自带标准图框属性块，也支持适配用户公司已有图框。

插入图框后，可以将图框中的图号、图名、比例等属性文字手动调整到公司图框中对应的位置，但不要炸开图框，否则属性块信息可能丢失，影响后续识别、目录生成和批量出图。

如果图幅不在属性中，也可以从图块名称中提取，例如 `A0`、`A1`、`A2+2` 等。

## V1.3 升级内容

- 标识清单中心：业务列显示复选框、全选/全不选、拖动排序，普通清单、CAD 表格及造价报表按选定列输出。
- 自定义映射：多块类型映射同一列、追加样本、稳定列标识、XML 模板保存/加载/编辑/另存/删除，支持模型、布局及跨文件提取和回写，提供独立汇总预览与导出。
- 高级图框编辑：不依赖图名或打印范围，支持筛选、批量填充、同值替换；可映射目录和打印字段。
- 本地电子签：角色、姓名属性和局部区域配置，一人多位置，重复同步和换人替换；图签保留姓名，会签始终隐藏姓名，仅导入实际使用的个人签名几何。
- `XYD_LINE2PL`（曲线转 PL）：接受各类有限曲线，含直线、圆弧、圆、矩形/已有多段线、旧式二维/三维多段线、椭圆、样条、螺旋线，以及多线和面域边界。设置统一使用 CAD 命令行关键词：`D` 切换是否保留数据、`Z` 切换是否统一 Z、`F` 设置拟合误差；输入容差或回车开始。默认不保留附加数据、顶点统一到世界坐标 Z=0。全部选中 PL 时自动按端点容差合并开放路径；支持预选、连续选择、多组、闭环、分叉、显示属性分组及整次撤销。
  保留数据开启时，同数据合并，冲突数据或独立关联分别转换，保留主对象句柄、XData、字典及关联；关闭时允许不同数据的线合并，生成 PL 不附带原数据。统一 Z 开启时，水平圆弧精确保留，倾斜圆弧及其他曲线按拟合误差投影；关闭时保留原高程及共面 PL / 非共面三维 PL。一次撤销恢复原对象及数据。
- `XYD_PLBREAK`（PL 打断）：选择一根 PL 后默认一点无缝分成两根，`M` 切换多点，两个内部点分成三根，回车统一执行；`U` 撤销上个暂存点、`S` 切回单点，Esc 取消整次操作。闭合 PL 单点打开、多点按环分段。支持轻量、旧式二维及三维 PL，保留全部线段、精确圆弧、分段宽度、原高程及数据，一次 CAD `U` 可恢复。
- 正式图库与 PMP 纳入版本控制；新增 A3+0.25、A3+0.5、A0+0.25、A0+0.5 并核验 A4，纸张按几何尺寸匹配，四段安装资源统一。

## V1.2 历史功能

- 自定义图库可按 DWG 勾选要显示的图块，隐藏主图块内部的辅助块。

- 新增查找相同，可按图层、图块名、线型、颜色等多个属性组合选择对象。

## 编译环境

项目按 AutoCAD 运行时分段编译：

- AutoCAD 2018-2024：.NET Framework。
- AutoCAD 2025-2026：.NET 8 Windows。
- 目标平台：x64。

生成四段 DLL 和单一安装包：

```powershell
powershell -ExecutionPolicy Bypass -File .\Packaging\Build-AutoCADPackage.ps1
```

安装包输出：

```text
Installer\Output\XYD_Toolkit_V1.3_AutoCAD2018-2026_Setup.exe
```
