XYDSignTool V1.3 正式纸张模板

正式来源：根目录 PMPFiles/XYD_PaperSizes.pmp。两个编译项目与四段安装包均复制该目录。
在批量打印选择 PC3 后点击“注入图纸尺寸”，会自动备份、关联 PC3/PMP 并刷新。

新增/核验尺寸（mm，按不含文字的图框几何边界）：
A4       210 x 297
A3+0.25  525 x 297
A3+0.5   630 x 297
A0+0.25  1486.25 x 841
A0+0.5   1783.5 x 841

图库 INSUNITS 为 Undefined，按原图库毫米制图约定处理。
原有 A1/A2 加长纸也已按该版图框实测尺寸校正，详细操作见 Docs/V1.3使用教程.md。
该模板是 PIAFILEVERSION_3.0,json 格式；注入时替换目标路径，旧二进制 PMP 仍兼容。
