# XYD Toolkit V1.3

程序集版本：1.3.0.0。适用于 AutoCAD 2018–2026，提供四段 DLL 和统一安装包。

## 主要更新

- 标识清单中心支持列显示勾选、拖动排序和按选定列输出；新增自定义属性映射、可复用 XML 模板、跨文件提取及属性回写。
- 高级图框编辑支持属性映射、筛选、批量填充和同值替换；本地电子签支持一人多位置及重复同步，图签保留姓名，会签始终隐藏姓名，仅导入实际使用的个人签名。
- `XYD_LINE2PL` 支持直线、圆弧、圆、既有多段线、椭圆、样条等可转换曲线，以及多线和面域边界；提供容差、保留数据和统一 Z 选项，全部选中 PL 时按端点容差合并。
- `XYD_PLBREAK` 支持一点或多点无缝打断 PL；闭合 PL 单点打开、多点按环分段，保留原曲线、宽度、高程和数据，支持一次撤销。
- 新增 `XYD_MSCALE` 批量缩放：各对象绕自身世界坐标包围盒中心（含真实 Z）等比例缩放，支持图块属性联动、预选和一次撤销。
- Ribbon 使用小图标、小字、每列最多三行；修复普通按钮、下拉按钮和菜单图标裁切，保留 CAD/天正选项卡及当前焦点。
- 修复 STB 图纸使用 CTB 批量出图时样式未生效的问题：在完整临时副本中转换后使用选定 CTB，包含已打开图纸的未保存内容，源 DWG 保持不变；支持取消、失败清理和旧 PDF 保护。
- 正式图库和 PMP 纳入版本控制，补齐新增图幅与纸张尺寸，四段安装资源统一。

## 安装与使用

1. 关闭所有 AutoCAD 窗口，运行 `XYD_Toolkit_V1.3_AutoCAD2018-2026_Setup.exe` 安装或覆盖更新。
2. 启动 AutoCAD，在“XYD 工具集”中使用功能。批量缩放输入 `2` 放大两倍、`0.5` 缩小一半，默认 `1` 不修改对象。
3. 批量出图时选择实际需要的 CTB；黑白 CTB 按黑白规则输出，自定义 CTB 按其颜色和线宽规则输出。
4. 映射模板、跨文件回写、电子签配置及曲线工具详见 [V1.3 使用教程](V1.3使用教程.md)。
