# XYDSignTool V1.3 使用教程

版本：V1.3 / 1.3.0.0。保持纯 C# WPF，无新增第三方依赖。

工具栏采用小图标、小字和三行排列。自动加载保留当前 CAD/天正选项卡，只有手动执行 `XYD_UI` 才切换到 XYD。如所有工具栏都不显示，请依次输入 `CLEANSCREENOFF`、`RIBBON`、`XYD_UI`。加载异常保存在 `%APPDATA%\XYDSignTool\Ribbon.log`，连续失败会停止自动重试。

## 清单中心

运行 `XYD_SIGN_CENTER`，选择当前图纸、多个已打开图纸或多个外部 DWG，再设置区域顺序。`XYD_CAD`、`XYD_XLS`、`XYD_COST` 保留，进入同一清单中心；`XYD_EDIT` 还提取“是否计数=否”的标识以便重新启用。

每个业务列有显示复选框，可全选、全不选、拖动表头排序。CAD 表格、普通 Excel、造价报表、清单 JSON 按所选列和顺序输出；隐藏面积、数量或价格列不会改变完整计算。造价单价管理仍按本次实际工艺确认单价，区域小计、合计适配已选列。

`XYD_JSON` 保存完整数据复用格式，包含备注、是否计数、中英文模式、工艺、尺寸和单价等字段；中心的“导出清单 JSON”只导出所选列。导入 JSON 数据可参与输出，没有源 DWG 的行不能回写。

## 属性映射模板

1. 运行 `XYD_SIGN_MAPPING`，点击“添加属性块样本”，选择一个或多个块。
2. 界面展示有效块名、属性标签、说明、示例、只读状态。勾选属性，为其填写清单列名。不同块类型可将不同标签映射到相同列名。同一块属性不能重复映射；一个块中的不同属性也不能争用同一编辑列。
3. 可继续添加样本，原有配置保留。点击“更新列设置”后修改列名、显示状态、汇总分组列；列名变化保留内部稳定标识及回写关系。
4. 需要汇总时勾选分组列并指定数量列，没有数量列则按实例计数。非分组列出现不同值时展示不同值集合。汇总只用于预览和导出，编辑与回写始终针对原始明细。
5. 填写模板名后保存、另存；下次加载后可编辑、追加样本或删除。也可直接“使用本次映射并提取”而不保存。
6. 选择已打开图纸或添加外部 DWG，选择模型、布局或全部空间。来源按完整路径去重，同一文件优先读取已打开的当前内存。

模板使用 XML，位于 `%APPDATA%\XYDSignTool\MappingProfiles`，保存列标识、顺序、显示状态、映射、汇总及签名设置。保存图框模板后，它会作为后续目录和打印的图框属性映射；没有图名映射的模板只用于高级编辑。现有图框识别规则继续兼容。

## 表格编辑与跨文件回写

可直接编辑，或选择目标列后筛选包含某内容的行，再对选中行、筛选结果、全部行“批量填入”。“同值替换”将指定范围内本列的精确旧值改为新值。所有操作先改表格，点击回写后才改 DWG。

回写核对文件标识、空间、句柄及待改属性原值，仅写入有变动的实际属性。中英文两行共享属性若改成不同值，会定位图块、属性和模式。常量、字段控制属性、外参、锁定对象和缺少来源的 JSON 明确受限。

已打开图纸只修改内存，等待手动保存。未打开图纸自动创建同目录的 `.XYDBackup_时间戳.bak`，然后按原 DWG 版本保存。按文件事务处理，任一冲突使该文件回滚，其他文件继续处理，结果窗口列出原因。需要恢复时保留当前 DWG，再将备份复制为 `.dwg`。

## 高级图框编辑

运行 `XYD_TITLEBLOCK_EDIT`，添加图框样本、映射属性并提取。空图名、封面及不能计算打印范围的图框仍可编辑。可把列用途设为图名、图号、比例、图幅、版本、日期、备注，供原目录和打印流程使用。

设计人、校对人、审核人等批量更换，可选中对应列，以旧姓名筛选或同值替换，检查表格后一次回写多个文件。

## 电子签首次配置

### 准备签名库和图框

- 签名库放在自己的本地目录，不要放入项目 `Blocks` 或安装资源中。
- 每个人一个独立图块，推荐“姓名=图块名”，例如属性值“张三”对应签名块“张三”。库中可以同时有 100 人，目标图纸只导入本次实际使用的个人几何。
- 使用线段、二维多段线、圆弧、圆、椭圆、样条或实心填充制作签名。普通文字按目标默认文字样式重建，不携带源字体字典；手写签名推荐独立矢量几何。其他对象如图片、OLE、代理对象不能隔离导入，应提前转为支持的几何。
- 每个人的图块不能引用其他人的签名、整库或外参。必要公共几何可使用 `XYD_SIG_GEOMETRY_` 前缀的辅助块，辅助块也只能包含必要几何。不要用该前缀命名人员签名。
- 图签与会签需使用独立姓名属性标签。例如 `DESIGNER` 和 `COUNTER_DESIGNER` 都可填“张三”，前者保留文字，后者始终隐藏文字，后台值仍保留用于编辑和匹配。

### 设置位置

1. 在高级图框映射中打开“电子签设置”，选择本地签名 DWG。
2. 系统自动按同名块建立对应。在人员表手动修正不一致的姓名或块名；一个姓名必须只有一个明确匹配。
3. 点击“添加签名位置”，选择图框样本，点选该签名区域的两个角。
4. 在位置表选择/填写姓名属性标签和角色。可使用设计、校对、审核、项目经理、负责人、会签或自定义角色。会签位置勾选“会签”；图签位置保持不勾选。
5. 一人多位置时重复添加位置；同一姓名属性可以关联多个区域。不同有效块名代表不同版式，分别设置位置。
6. 选中人员和位置，预览签名，检查宽高，然后“应用本次设置”或“应用并保存模板”。位置保存为图框局部坐标，随目标图框移动、旋转和缩放，签名按区域等比缩放。

### 提取后应用

“增加 / 同步电子签”默认关闭。直接回写也会执行文字规则：图签保留姓名；会签始终不显示姓名，无论是否加电子签。

勾选后回写，系统预检所有非空姓名。缺少签名块、姓名匹配不唯一、嵌套人员签名或无法隔离的对象会显示图框、角色和原因，并回滚该文件。空姓名保留空栏。

重复执行替换原位置，不叠加；更换姓名会替换对应签名，清理本插件生成且无引用的旧签名定义。取消添加复选框不删除既有签名；要删除请点击“移除生成签名”。目标 DWG 不携带完整库或完整人员索引，模板在本地保存库路径和匹配设置。

## 曲线转 PL

点击小图标“曲线转 PL”，或运行 `XYD_LINE2PL`。可以先选对象再运行，也可以先运行后连续点选/框选，回车完成，Esc 取消。接受各类有限曲线：直线、圆弧、圆、矩形/轻量多段线、旧式二维/三维多段线、椭圆/椭圆弧、样条、螺旋线；多线和面域会提取其边界生成 PL。矩形本身通常已经是闭合多段线，本命令保留其闭合形状。

设置使用 CAD 原生命令行关键词，点击选项或输入对应字母即可修改，再回到同一提示。命令显示当前全部设置，不会逐项询问：

```text
设置端点合并容差（回车使用 0.01）或 [是否保留数据(D)/是否统一Z坐标(Z)/拟合误差(F)]:
```

直接输入**端点合并容差**或回车，开始转换/选择对象。容差按图纸单位，首次 0.01，允许为零，记住上次使用值。`D` 直接切换数据保留，**每次运行默认不保留**；`Z` 直接切换统一 Z，**每次运行默认统一到世界坐标 Z=0**。`F` 进入拟合误差设置，设置后回到主提示；拟合误差首次 0.01，必须大于零，记住上次值，转换椭圆、样条时直接使用该值。例如要保留数据和原高程，依次输入 `D`、`Z`，最后输入容差或回车；要修改拟合精度，输入 `F`、新的正数，再输入容差或回车。

拟合误差控制曲线与生成折线的偏差，数值越小顶点越多；例如单位为毫米时，0.01 表示约 0.01 毫米的拟合精度。合并容差和拟合误差独立，合并容差设为零仍可转换椭圆、样条。

统一 Z 开启时保留 X/Y 坐标，把顶点投影到世界坐标 Z=0，不受当前 UCS 影响；合并按投影后的端点判断。水平圆弧保留精确圆弧段，水平圆生成四段圆弧组成的闭合 PL，保留半径、面积和周长。倾斜圆弧/圆的 XY 投影通常是椭圆，按拟合误差生成折线，不用错误的圆弧替代；已有多段线的分段宽度按原段参数插值保留。纯竖直线投影后没有长度，会保留原对象并提示；路径内的竖直段消去重复投影顶点。厚度数值保留，统一 Z 时拉伸方向统一为世界 Z 轴。

统一 Z 关闭时保留原高程、共面路径的平面与精确圆弧；非共面路径生成三维 PL，其中圆弧按误差拟合。椭圆、样条、螺旋线及拟合旧式多段线在两种模式下都按拟合误差处理。闭合状态保留。

端点在容差内时保留当前模式下的端点并补短连接，不移动 X/Y 顶点。多组生成多条 PL，孤立线也转为两顶点 PL；闭环生成闭合 PL，分叉拆成独立路径。**所选对象全部是 PL 时自动执行合并**：支持轻量、旧式二维和三维 PL，按相同的显示属性及端点容差连接，保留圆弧和分段宽度；已闭合轮廓保持独立。内部交叉不会自动拆分，不同图层、颜色、线型、线宽等属性分别处理。

带 **XData 或扩展字典**的线也能转换。默认**不保留数据**，不同数据、独立字典或关联不阻止合并，生成 PL 不附带原 XData、扩展字典或关联；原对象及其关联被替换，图层、颜色、线型等显示属性仍保留。

需要保留时选择 `D`。开启后，XData 完全相同的线按容差合并；数据不同的线分别生成 PL。带独立扩展字典、句柄引用或持久关联的对象独立转换，保留主对象句柄、XData、完整扩展字典和关联记录。多线/面域的字典保存在第一条主 PL，其他边界复制 XData，原生组包含所有生成边界。合并时保留主对象句柄，其他被合并线的独立句柄结束使用。

一次 AutoCAD `U` 可恢复整次操作及原附加数据。多线或面域可能生成多条 PL，所有边界成功后才替换原对象，失败时整组回滚。零长度、锁定、没有有限端点的无限直线/射线，以及无法保留宽度/厚度的三维路径均保留并报告原因。图块、文字、尺寸和填充不作为曲线自动炸开。附加数据保留不代表其他软件的构件编辑功能一定支持转换后的 PL 类型。

## PL 无缝打断

点击“统计与测量”中的小图标 **PL 打断**，或运行 `XYD_PLBREAK`。选择一根 PL 后再指定断点，也可以预选一根 PL 再运行。支持轻量、旧式二维和三维 PL。

每次运行默认**单点模式**，命令提示：

```text
指定打断点或 [多点(M)]:
```

在开放 PL 的内部指定一个点，立即得到两根 PL；两根线的端点重合，原线全部保留，不挖空，不产生缺口。可以用对象捕捉定位；离线点投影到所选 PL，按当前 UCS 解读输入坐标。

需要多个断点时，点击“多点”或输入 `M`，连续点选，**回车后统一执行**。两个不同内部断点得到三根开放 PL，三个点得到四根。按断点在线上的位置排序，不要求依次点选。重复点和开放线两端的点跳过，不生成零长度段。

| 多点模式操作 | 结果 |
| --- | --- |
| 回车 | 根据已暂存断点一次完成分段 |
| `U` | 撤销最后一个暂存断点，保留其他点 |
| `S` | 切回单点，清除暂存点，重新指定一个点 |
| Esc | 取消整次操作，原 PL 保持原样 |

**闭合 PL 按环处理**：单点打开为一根开放 PL，起点和终点都在该断点；两个不同点分成两根，三个不同点分成三根。不会把原起点偷偷增加为断口，也不会删除原闭合边。闭合线的起终参数对应同一个位置，只计一个断点。

打断保留原圆弧、分段宽度、厚度、法向、原高程、图层、颜色和线型等属性；此命令不压平 Z，也不使用曲线转换的拟合误差。宽度在断点处按原段参数插值，两侧一致。主段保留原句柄和扩展字典，全部分段复制 XData，原生组包含各分段。一次 AutoCAD `U` 撤销整个打断，恢复原几何、闭合状态和数据。锁定图层或零长度 PL 保留并提示。

## 图框和打印纸张

正式图库为根目录 `Blocks`，PMP 为根目录 `PMPFiles`，构建及四段安装包均取正式资源。新版图框已复制到安装资源目录，旧文件已有备份。

| 新图幅 | 纸张尺寸（mm） |
| --- | --- |
| A4 | 210 × 297 |
| A3+0.25 | 525 × 297 |
| A3+0.5 | 630 × 297 |
| A0+0.25 | 1486.25 × 841 |
| A0+0.5 | 1783.5 × 841 |

尺寸来自图框几何外边界，不包含属性文字。原 DWG 的 INSUNITS 为 Undefined，沿用该图库毫米制图与纸张约定。部分图库名称为 `MyTitleBlock_*` 或 `A1+0.75`，插入时按精确图幅别名导入为原有 `XYD-TITLEBLOCK_*` 名称，源库不被修改；A4 使用已有入口。

批量打印选择目标 PC3 后点击“注入图纸尺寸”，自动备份 PC3/PMP、关联模板并刷新。A0、A3 不会误选加长纸。布局、UCS、居中、图片打印及打印预检沿用现有流程。

### CTB 自动转换出图

预检中仅显示实际可用的 `.ctb` 文件，按您选择的样式输出；选择 `monochrome.ctb` 使用黑白规则，选择彩色或自定义 CTB 使用其颜色和线宽规则。

系统按图纸数据库的实际模式检查 CTB/STB。全部出图使用完整临时副本，STB 副本先自动转换成 CTB，转换结束、样式验证通过后再打印。原 DWG 的打印模式、命名样式分配和磁盘文件保持不变。已打开图纸按当前内存内容输出，包含未保存修改；未打开文件只读加载。模型、布局和相对外参、图片、底图路径保留。

任务按完整来源路径区分同名文件，并为每个来源建立一份打印副本。失败会在命令行给出来源和原因，成功、失败或取消均清理临时副本并恢复原活动图纸。Esc 取消，或输入 `XYD_BATCHPRINT_CANCEL` 停止队列。已有 PDF 在新结果成功后替换，失败不覆盖旧结果。

## 批量缩放

点击“统计与测量”中与“批量旋转”同列的 **批量缩放**，或运行 `XYD_MSCALE`。可预选对象，也可运行命令后点选、框选，回车结束选择。

输入一个正倍率：`2` 放大两倍，`0.5` 缩小一半；回车使用默认 `1`，不修改对象。零和负数不接受，Esc 取消输入后不修改对象。

每个对象分别以自身 **世界坐标包围盒中心**等比例缩放，包含真实 Z 坐标，对象中心和各中心之间的距离保持不变。图块只变换当前实例，属性位置、字号随图块自动变化，共享定义和其他实例保持原样。父图块与属性重复选择时去重。

锁定、只读、边界异常或无法变换的对象保留，并汇总原因。一个对象及其属性作为整体提交或回滚；完成后一次 AutoCAD `U` 撤销整次缩放。
